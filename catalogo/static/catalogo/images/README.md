# Logos Corporativos

Esta carpeta debe contener los logos corporativos de Bensulco Distribution y Blixi.

## Archivos Requeridos:

1. **bensulco-logo.png**
   - Logo de Bensulco Distribution
   - Altura recomendada: 50px
   - Formato: PNG con transparencia
   - Ubicación: Colocar en este directorio

2. **blixi-logo.png**
   - Logo oficial de Blixi
   - Altura recomendada: 50px
   - Formato: PNG con transparencia
   - Ubicación: Colocar en este directorio

## Notas:

- Los logos se muestran automáticamente en el encabezado del catálogo
- Si un logo no está disponible, el espacio se colapsa automáticamente (gracias al atributo onerror)
- Los logos deben ser de alta calidad para mantener la apariencia profesional
- Se recomienda usar PNG con fondo transparente para mejor integración con el fondo morado

## Instrucciones:

1. Coloque los archivos de logo en este directorio
2. Los nombres deben ser exactamente `bensulco-logo.png` y `blixi-logo.png`
3. El sistema detectará automáticamente los logos y los mostrará en el encabezado
